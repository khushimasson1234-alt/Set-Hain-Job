Set Hain Trust Score™

Trust, made visible.

Every saathi carries a score built from real signals — not self-reported claims.

  • Identity verification
  • Skill verification
  • Completed jobs
  • Customer reviews
  • Cancellation rate
  • Dispute history
Identity + skill verification form the base score. Completed jobs and customer reviews build it up over time. A high cancellation rate or an open dispute pulls it back down — so the number reflects real, recent reliability rather than a one-time check.
