# Set Hain Job — Hyperlocal Skill & Employment Platform

Set Hain Job is a web-based hyperlocal employment platform designed to connect people with nearby work opportunities, skilled professionals, and services.

The platform focuses on location-first matching, helping users discover relevant opportunities and talent within their locality while considering factors such as skills, trust, availability, and pricing.

## Key Features

- 🔎 Find Work and Hire Talent modes
- 📍 Hyperlocal, location-based matching
- 🗺️ Interactive map powered by OpenStreetMap
- 🎤 Voice-based search interface
- 🤖 AI-powered matching concept
- 🪪 Skill Passport with trust and verification information
- 🛡️ Safety and scam-protection features
- 🏠 Work-from-home opportunities
- 👩 Women-first opportunity filters
- ⏰ Flexible and daytime work options
- 🔄 Saathi Swap — skill exchange using Set Credits
- 📊 User dashboard and notifications
- 📱 Responsive and user-focused interface

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Leaflet.js
- OpenStreetMap

## Project Objective

The goal of Set Hain Job is to make employment and skill-based opportunities more accessible by prioritizing **location, skills, trust, availability, and accessibility** rather than relying only on traditional resumes.

## Project Status

🚧 Prototype / Development Project

This project is currently being developed as a functional web prototype and can be extended with a backend, database, user authentication, real-time job listings, and production-grade AI matching.
